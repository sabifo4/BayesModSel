# TEST CASE 1: a Bayesian model selection analysis on the origin of placental mammals

## Diversification models for the origin of placental mammals evaluated under a Bayesian model selection analysis

As our first test case, we assessed how two diversification models on the origin of placental mammals fit the 72-mammal dataset (sequence alignment and calibrated tree topology) assembled by [Álvarez-Carretero et al. (2022)](https://www.nature.com/articles/s41586-021-04341-1):

* **_Unconstrained_**: this diversification model does not constrain the age of node Placentalia to any specific geological event. Instead, the maximum age of the calibration density used to constrain the age of node Placentalia is informed by fossil <i>†Juramaia</i>, at ca. 162.5 Ma [Benton et al. (2011)](https://palaeo-electronica.org/content/pdfs/424.pdf). This interpretation of the fossil record was also followed by a study of ours, [Álvarez-Carretero et al. (2022)](https://www.nature.com/articles/s41586-021-04341-1), in which, when combining genomic data and fossil evidence across the mammal tree using a Bayesian sequential subtree approach, we estimated the age of node Placentalia at ca. 80 Ma. [Our `Fossil_calibrations_justification.pdf` file](https://github.com/sabifo4/mammals_dating/blob/main/calibrations/Fossil_calibrations_justifications.pdf) contains all the details justifying the calibration densities we used across the 72-taxa phylogeny we used in our study. Please note that we have used the tag `ACetal22` (i.e., initials of the first author in the study followed by the year it was published) to rename files/directories and identify the analyses carried out under the assumptions of this diversification model. In this study, we have used the calibrated tree file [`72sp_ACetal22.tree`](00_data_formatting/trees/ACetal22/72sp_ACetal22.tree), which includes all the node age constraints under the **_Unconstrained_** diversification model in `MCMCtree` notation; this is the same file that we used in [Álvarez-Carretero et al. (2022)](https://www.nature.com/articles/s41586-021-04341-1). We tested this model under both **GBM** (Geometric Brownian motion, or autocorrelated) and **ILN** (independent log-normal) relaxed-clock models.
* **_Post-K-Pg_**: based on a literal interpretation of the fossil record, [Budd and Mann (2024)](https://doi.org/10.1093/sysbio/syad057) suggest that the age of node Placentalia **cannot** pre-date the K-Pg mass extinction event (66.09 Ma), which disagrees with the mammal evolutionary timeline we inferred in ACetal22 and the **_Unconstrained_** diversification model. Consequently, the maximum age of node Placentalia under this model has been constrained using a hard bound. Please note that we have used the tag `BM23pUhb` (i.e., initials of the authors in the study followed by the year it was published online [2023] and then by the initials of the type of constraint place on the age of node Placentalia: tail **p**ercentage of the **U**pper bound in the calibration density has a **h**ard **b**ound) to rename files/directories and identify the analyses carried out under the assumptions of this diversification model. We may therefore use either `BM23` or `BM24` when referring to the study of [Budd and Mann (2024)](https://doi.org/10.1093/sysbio/syad057), but both refer to the same study. The calibrated tree file [`72sp_BM23pUhb.tree`](00_data_formatting/trees/BM23pUhb/72sp_BM23pUhb.tree) we have used in this study includes all the node age constraints under hypothesis "post-K-Pg" in `MCMCtree` notation; this is the same file that was used by [Budd and Mann (2024)](https://doi.org/10.1093/sysbio/syad057) but includes the tail probability "1e-300" instead of "0.025" to enforce a hard maximum on node Placentalia. We tested this model under both **GBM** and **ILN** relaxed-clock models.

> Table 1. Diversification models that were tested under a Bayesian model selection for the origin of placental mammals. Calibration densities for node Placentalia were uniform densities with a soft minimum age set to 61.66Ma based on fossil specimen _†Ravenictis krausei_. Maximum ages depend on the diversification model being tested. The dataset being analysed was assembled by ACetal22, and consists of 15,268 whole genomes for 72 mammal species ordered from slow- to fast-evolving and then partitioned into four alignment blocks (3,817 orthologs per block). The number of base pairs for each alignment block is the following: 8,926,316 bp (partition 1), 8,339,196 (partition 2), 8,605,264 (partition 3), and 7,302,398 (partition 4).

As aforementioned, please remember that we have used the following tags to rename files/directories and identify the analyses carried out under the assumptions of a specific diversification model:

* `ACetal22`: tag used to rename files/directories and identify analyses where the diversification model used by [Álvarez-Carretero et al. (2022)](https://www.nature.com/articles/s41586-021-04341-1) has been integrated.
* `BM23pUhb`: tag used to rename files/directories and identify analyses where a post-K-Pg hypothesis based on the diversification model postulated by [Budd and Mann (2024)](https://doi.org/10.1093/sysbio/syad05) has been integrated.

## Navigating this GitHub repository for data reproducibility

In order to easily navigate through our analyses and reproduce our results, please follow the links in the file structure below:

* [`00_data_formatting`](00_data_formatting/README.md): in this directory, you will find a description of the input files (sequence alignment and tree files) we have used to run our Bayesian model selection analyses.
  * [`aln`](00_data_formatting/aln): the [`in.BV`](00_data_formatting/aln/in.BV) and the [`dummy.txt`](00_data_formatting/aln/dummy.txt) files can be found in this directory. As you will see when you read the corresponding [README.md](00_data_formatting/README.md#input-files) file, we are not able to host the large alignment (`alignment_4parts.aln`) file on GitHub, and thus a dummy file of reduced size is used instead. Please go through the the [README.md](00_data_formatting/README.md#input-files) file and follow the instructions to download the `alignment_4parts.aln` file should you need it for other analyses you may be keen on carrying out. Please note that we **do not need this alignment file for the Bayesian model selection analysis discussed in this repository**; we can save computational resources as less time will be spent when reading the [`dummy.txt`](00_data_formatting/aln/dummy.txt) (more info in the [README.md file](00_data_formatting/README.md#input-files)).
  * [`trees`](00_data_formatting/trees)
    * [`ACetal22`](00_data_formatting/trees/ACetal22): the [`72sp_ACetal22.tree` file](00_data_formatting/trees/ACetal22/72sp_ACetal22.tree) includes the node age constraints following [Álvarez-Carretero et al. (2022)](https://www.nature.com/articles/s41586-021-04341-1) (i.e., **_Unconstrained_** diversification model).
    * [`BM23pUhb`](00_data_formatting/trees/BM23pUhb): the [`72sp_BM23pUhb.tree` file](00_data_formatting/trees/BM23pUhb/72sp_BM23pUhb.tree) includes the same node age constraints following [Budd and Mann (2024)](https://doi.org/10.1093/sysbio/syad057) except for the maximum age constraint placed on node Placentalia: a strict hard bound is used instead of a soft bound.
* [`01_modsel_workflow`](01_modsel_workflow/README.md): in this directory, you will see one directory for each step that needs to be run. Directory names refer to the main program used to carry out the main analysis under each step.
  * [`00_mcmc3r`](01_modsel_workflow/00_mcmc3r/): the first step on our Bayesian model selection analysis consists of using the `mcmc3r` R package ([dos Reis et al. (2018)](https://doi.org/10.1093/sysbio/syy001)) to prepare the file structure and control files that will be subsequently used by `MCMCtree`.
    * [`control_template`](01_modsel_workflow/00_mcmc3r/control_template): [the template control file](01_modsel_workflow/00_mcmc3r/control_template/mcmctree_tmp.ctl) with the same settings we used for timetree inference in [Álvarez-Carretero et al. (2022)](https://www.nature.com/articles/s41586-021-04341-1) when analysing the 72-taxa mammal tree can be found in this directory. This template file is used by [our in-house `R` script](01_modsel_workflow/00_mcmc3r/scripts/Generate_BFs_inp.R), which appends the beta value to each control file that `MCMCtree` will use when sampling from the corresponding power posteriors.
    * [`MCMCtree`](01_modsel_workflow/00_mcmc3r/01_MCMCtree/): directory generated by [our in-house `R` script](01_modsel_workflow/00_mcmc3r/scripts/Generate_BFs_inp.R) with all the updated control files (i.e., same settings as in our [template control file](01_modsel_workflow/00_mcmc3r/control_template/mcmctree_tmp.ctl) but with a new line including the corresponding beta value that will be used during the MCMC when sampling from the corresponding power posterior). There are as many directories as power posteriors required to approximate the marginal likelihood for this dataset (i.e., 256). Please read the corresponding [README.md file](01_modsel_workflow/README.md#1-run-mcmc3r-to-select--values) to learn more about how you can run our in-house `R` script to generate the file structure that `MCMCtree` will later use.
    * [`scripts`](01_modsel_workflow/00_mcmc3r/scripts): [our in-house `R` script](01_modsel_workflow/00_mcmc3r/scripts/Generate_BFs_inp.R) to run `mcmc3r` and generate the files structure that `MCMCtree` so that it samples from the power posteriors can be found here. Please read the corresponding [README.md](01_modsel_workflow/README.md#1-run-mcmc3r-to-select--values) file to learn how to execute this script and reproduce our results.
  * [`01_MCMCtree`](01_modsel_workflow/01_MCMCtree/): this directory contains the file structure required to run `MCMCtree` when sampling from the power posteriors. A directory for the script used to build such a structure is also provided.
    * [`HPC`](01_modsel_workflow/01_MCMCtree/HPC/): this directory contains all the various subdirectories that will be transferred to the HPC to run the Bayesian model selection analysis. Please read the corresponding [README.md](01_modsel_workflow/README.md#2-run-mcmctree) file to learn how to execute this script and reproduce our results.
    * [`scripts`](01_modsel_workflow/01_MCMCtree/scripts): this directory contains the in-house bash scripts that we used to create the file structure to run `MCMCtree`. The commands to execute them can be found in the [main `README.md` file inside the `01_modsel_workflow` directory](01_modsel_workflow/README.md).
  * [`02_mcmc3r`](01_modsel_workflow/02_mcmc3r/): once the analyses with `MCMCtree` have finished, we can analyse the samples collected during the MCMC when sampling from each power posterior and estimate the marginal likelihood (as well as the corresponding S.E. and the posterior probabilities for each hypothesis tested) with the `mcmc3r` R package.
    * [`HPC`](01_modsel_workflow/02_mcmc3r/HPC/): this directory contains all the input and output files required/generated by `MCMCtree` (more details in [section `2. Run MCMCtree` in the `README.md` file available within the `01_modsel_workflow` directory](01_modsel_workflow/README.md#2-run-mcmctree)). Please note that the 256 $\beta$ points used to sample from the corresponding 256 power posteriors are previously calculated by the `mcmc3r` R functions included in [our in-house `R` script](01_modsel_workflow/00_mcmc3r/scripts/Generate_BFs_inp.R), which are then saved in the `betaweights.txt` file. The `mcmc.txt` file output by `MCMCtree` (i.e., the sampled likelihood terms are saved in this file, which is output for each diversification model and for each power posterior) is read by various `mcmc3r` R functions, alongside the previously generated `betaweights.txt` file, to estimate the marginal likelihood value of each diversification model (more details in the [section `3. Run mcmc3r to estimate marginal likelihood values` available within the `01_modsel_workflow` directory](01_modsel_workflow/README.md#3-run-mcmc3r-to-estimate-marginal-likelihood-values)).
    * [`scripts`](01_modsel_workflow/02_mcmc3r/scripts/): this directory contains [our in-house `R` script](01_modsel_workflow/02_mcmc3r/scripts/Calculate_mlnL_BFs.R) to estimate the marginal likelihood, compute BFs, and posterior probabilities that we will use to select the best-fitting model to the 72-taxa mammalian dataset. Please read [the corresponding section in the `README.md` file](01_modsel_workflow/README.md#3-run-mcmc3r-to-estimate-marginal-likelihood-values) to learn how to execute this script and reproduce our results.
* [`02_rate_per_branch`](02_rate_per_branch/README.md): in this directory, you will see one directory for each step that needs to be followed when running `MCMCtree` under the approximate likelihood calculation while printing the branch rates (i.e., `print = 2`).
  * [`00_MCMCtree`](02_rate_per_branch/00_MCMCtree/)
    * [`HPC`](02_rate_per_branch/00_MCMCtree/HPC): within this directory, you will find the file structure with the input files we will upload on a server to run `MCMCtree`. The first section in the [`README.md` file](02_rate_per_branch/README.md#1-run-mcmctree) includes various code snippets that you can use to prepare the contents within this directory while including tips to transfer this to a server.
    * [`scripts`](02_rate_per_branch/00_MCMCtree/scripts/): this directory includes two scripts that are used to obtain the bash scripts that will be submitted to a server to run `MCMCtree` (i.e., job arrays). If you have a different schedulers to SGE, then you will need to adapt these scripts if you want to follow the step-by-step guidelines detailed in the [`README.md` file](02_rate_per_branch/README.md#1-run-mcmctree).
    * `sum_analyses`: this is a directory that cannot be committed to GitHub due to its large size. If you follow the guidelines from the second section in the [`README.md` file](02_rate_per_branch/README.md#2-analyses-with-mcmctree-when-sampling-from-the-prior) onwards, you shall be able to reproduce its contents. You can download the original `sum_analyses` directory from our [FigShare repository](https://doi.org/10.6084/m9.figshare.32033958) and save it in this directory if you want to continue with the subsequent MCMC diagnostics.
  * [`01_MCMC_diagnostics`](02_rate_per_branch/01_MCMC_diagnostics/)
    * [`calibs`](02_rate_per_branch/01_MCMC_diagnostics/calibs/): this directory includes the [`R` script](02_rate_per_branch/01_MCMC_diagnostics/calibs/scripts/Include_calibrations_MCMCtree.R) alongside the [input `csv` files](02_rate_per_branch/01_MCMC_diagnostics/calibs/raw) required to generate the calibrated tree files in `MCMCtree` format. The [`raw` directory](02_rate_per_branch/01_MCMC_diagnostics/calibs/raw) includes both the input `csv` files and output files generated by the [`R` script `Include_calibrations_MCMCtree.R`](02_rate_per_branch/01_MCMC_diagnostics/calibs/scripts/Include_calibrations_MCMCtree.R). The [`inp_calibs` directory](02_rate_per_branch/01_MCMC_diagnostics/inp_calibs) contains files output by a subsequent in-house `R` script that will be run during MCMC diagnostics.
    * [`dummy_aln`](02_rate_per_branch/01_MCMC_diagnostics/dummy_aln/): dummy alignment with the same taxa names as those in the input tree files but only two nucleotides. This alignment is read much quicker by `MCMCtree` than a full alignment and, given that sequence data are not required for MCMC diagnostics, we will save time when `MCMCtree` reads both input files to check that the taxa names are the same (i.e., this file is used when `MCMCtree` is run when `print = -1`).
    * [`dummy_ctl_files`](02_rate_per_branch/01_MCMC_diagnostics/dummy_ctl_files/): template control file that is used at the end of the MCMC diagnostics to generate the evolutionary timeline that summarises the estimated evolutionary timelines across all the chains that passed the filters (i.e., this file is used when `MCMCtree` is run when `print = -1` as detailed in the relevant sections in the [`README.md` file](02_rate_per_branch/README.md)).
    * [`out_RData`](02_rate_per_branch/01_MCMC_diagnostics/out_RData/): some relevant output files generated by our in-house `R` scripts are saved here (saving the largest files with extension `RData` is optional, users can decide whether they want to output them or not).
    * `plots`: all the plots generated by our in-house `R` scripts are saved in this directory. The plots the R scripts save in this directory have been saved under their corresponding subdirectories in `sum_files_post` and `sum_files_prior`. You can download the `plots` directory we generated from our [FigShare repository](https://doi.org/10.6084/m9.figshare.32033958).
    * [`scripts`](02_rate_per_branch/01_MCMC_diagnostics/scripts/): all the `R` scripts that are used to carry out MCMC diagnostics are saved in this directory. The order in which they need to be used is detailed in the [`README.md` file](02_rate_per_branch/README.md), and the comments within each script clarify what tasks are completed by our in-house functions, which input files are required, and which output files shall be generated.
    * [`sum_files_post`](02_rate_per_branch/01_MCMC_diagnostics/sum_files_post/): at the end of the MCMC diagnostics, there are a set of code snippets that extract the most relevant output files generated by our in-house `R` scripts when summarising the data when sampling takes place from the posterior. These output files are classified in different subdirectories depending on what they are informative about.
    * [`sum_files_prior`](02_rate_per_branch/01_MCMC_diagnostics/sum_files_prior/): at the end of the MCMC diagnostics, there are a set of code snippets that we have included in the [`README.md` file](02_rate_per_branch/README.md) that we use to extract the most relevant output files generated by our in-house `R` scripts when summarising the data when sampling takes place from the prior. These output files are classified in different subdirectories depending on what they are informative about.
  * [`02_Summary_Rates`](02_rate_per_branch/02_Summary_Rates)
    * [`00_prior`](02_rate_per_branch/02_Summary_Rates/00_prior/): we use bash scripting as detailed in various code snippets in the [`README.md` file](02_rate_per_branch/README.md) to extract the "rategrams" (i.e., lines with the tree topologies and the branch rates as labels printed on the `out.txt` files generated by `MCMCtree` when `print = 2`) for each chain and partition (this procedure is carried out for each model and under both clocks).
    * [`01_posterior`](02_rate_per_branch/02_Summary_Rates/01_posterior/): we use bash scripting as detailed in various code snippets in the [`README.md` file](02_rate_per_branch/README.md) to extract the "rategrams" (i.e., lines with the tree topologies and the branch rates as labels printed on the `out.txt` files generated by `MCMCtree` when `print = 2`) for each chain and partition (this procedure is carried out for each model and under both clocks).
    * [`plots`](02_rate_per_branch/02_Summary_Rates/plots/): for each model and relaxed-clock model, we used [our in-house `R` script](02_rate_per_branch/02_Summary_Rates/scripts/Summarise_brates_mammals.R) to plot the evolutionary timelines with colour-coded branch lengths (i.e., ranging from faster- to slower-evolving rates) for each partition and then showing the average evolutionary rate per branch per model under each relaxed-clock model.
    * [`scripts`](02_rate_per_branch/02_Summary_Rates/scripts/): in this directory you can find [our in-house `R` script `Summarise_brates_mammals.R`](02_rate_per_branch/02_Summary_Rates/scripts/Summarise_brates_mammals.R), which we use to generate the abovementioned plots.
  * [`figs_tables`](02_rate_per_branch/figs_tables/): summary tables and figures that are output in a relevant format almost-ready to be used to include in a manuscript.
    * `out_RData`: object that summarises the evolutionary timelines estimated under each diversification model and relaxed-clock model (users can decide whether this object is to be saved when running our in-house `R` script).
    * [`plots`](02_rate_per_branch/figs_tables/plots/): all plots comparing the estimated divergence times for calibrated and uncalibrated nodes generated by out in-house `R` scripts are saved here.
    * [`scripts`](02_rate_per_branch/figs_tables/scripts/): the in-house `R` scripts that generate all [`plots`](02_rate_per_branch/figs_tables/plots/) and [`tables`](02_rate_per_branch/figs_tables/tables/) are saved here.
    * [`tables`](02_rate_per_branch/figs_tables/tables/): all tables comparing the estimated divergence times for calibrated and uncalibrated nodes generated, as well as the MCMC diagnostics under each model, are saved here.
